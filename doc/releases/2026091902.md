# ZIMA-CAD-Parts 2026091902

The existing parameter reload now imports saved ZIMA-CAD Parts (`.prtz`) and
Assemblies (`.asmz`) into the same configured metadata columns as Pro/E.
Internal parameter keys and localized names support historical Czech handles
such as `nazev` and `polotovar`. Native values take precedence over same-named
Pro/E exports; numbered native archives and Drawings are excluded.

Literal UTF-8 values are preserved. Empty values do not erase existing metadata,
and ambiguous name aliases are ignored. Source CAD documents remain unchanged.

The implementation passed 59 integration checks, 18 CLI tests and translation
validation. Signed Windows package acceptance is recorded after clean builds,
package checks and publication. This release contains Windows only.
