# ZIMA-Parts 2026092903

This is the independent ZIMA-Parts product explicitly requested and approved
by the user. GUI, CLI, updater, launchers, package root, archive names, tags
and signed product identity now use ZIMA-Parts. The GitHub endpoint is the
renamed repository. Older installations are not migrated by this release.

Application settings, browser data and the credential service use the new
ZIMA-Parts identity. Old-product data is not deleted or migrated.
The Windows executable is ZIMA-Parts.exe. Visible branding remains localized
in all five supported languages.

Renaming also removes hard-coded old-prefix lengths from release discovery
and ZIP entry extraction. Prefix lengths now follow their actual strings.
Windows build, localization, CLI, integration and isolated signed-update
checks are required before publishing the new product.
