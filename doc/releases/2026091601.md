# ZIMA-CAD-Parts 2026091601

## PTC Cleaner

- Automatically load the file list when opening Cleaner from a directory and
  refresh it after changes to recursion, old-version rules or removal masks.
- Use the selected Parts directory directly. Remove the source field, browse
  buttons and manual Preview button; put options below the file list.
- Replace Apply selected with Clean and retain confirmation before recycling.
- Remove successfully cleaned rows; preserve unchecked files and report failures.
- Recycle Windows selections in one background Shell operation and refresh the
  affected directory after the batch. The Cleaner window leaves Parts usable.
- Reuse each file hash within a scan, including shared retained revisions.
- Preserve directory locks, changed-file checks, AI approval snapshots and the
  rule that unavailable recycling never falls back to permanent deletion.

## Verification

Development verification passed 51 GUI integration checks, 9 built-in tool tests,
4 read-only CLI tests and all four translation catalogs. The Czech dialog was
visually checked. A 128-file Windows fixture improved from 7.145 to 1.842 seconds;
actual performance depends on the storage and files. Release package acceptance
is recorded in the build verification document after packaging.

This release targets Windows x64. It includes the matching source code and the
signed updater metadata. Linux runtime verification remains separate.
