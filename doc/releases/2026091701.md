Debian target, rather than a separately provisioned VM. Browser/credential/CAD
checks use a harness with application objects and packaged runtime dependencies;
the exact shipped executable also received its own startup probe. Installation
and rollback coverage uses isolated signed fixtures, not a prior official Linux
release (this is the first one). A KDE theme discrepancy for the Russian standard
Cancel button remains documented. These checks are not an exhaustive audit of
every browser login flow or every Debian hardware configuration.
