# ZIMA-CAD-Parts 2026091701 — Debian 13 candidate

This draft provides an unsigned Linux x86-64 bundle with Qt 6.8.2,
WebEngine, OCCT, CLI, updater and matching sources. Extract the ZIP and run
`ZIMA-CAD-Parts/ZIMA-CAD-Parts.sh`. Debian 13 is the target system;
Ghostscript must be installed separately for PS2PDF.

Fix the updater build on GCC by avoiding the predefined `linux` macro,
and place application objects before OCCT libraries in integration tests.
Use keyboard selection for the menu fixture so pending native popup geometry
does not invalidate the test. Ignore generated Qt translation and D-Bus files.

The candidate is not signed and is not eligible for automatic updates.
Publisher signing, complete dependency-license inventory and clean-machine
acceptance (including passwords, PDF/web rendering, relocation and rollback)
remain required before publication. A KDE platform-theme translation discrepancy
for the standard Russian Cancel button was observed in the Wayland test run.

Verification: 51 GUI integration checks (offscreen), 4 CLI checks, 9 tool
checks and 18 updater checks passed. Distribution: 3 passed, 1 Windows-only
skip. All four application translation catalogs passed. Native Wayland menu
selection and packaged GUI startup were also checked.
