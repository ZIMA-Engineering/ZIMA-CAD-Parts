# ZIMA-CAD-Parts 2026091801

## PostScript to PDF

- Use the same automatic, modeless workflow as PTC Cleaner. The selected Parts
  directory is scanned without a redundant source selector or Preview button.
- Create PDFs in the relative `pdf` subdirectory by default and create that
  directory when conversion starts.
- Replace an existing PDF atomically after Ghostscript has generated and
  validated its replacement. A failed conversion preserves the previous PDF.
- Add **Delete PS source files after creating PDF**. It is disabled by default
  and removes each PS, EPS or PostScript PLT source only after its PDF is saved.
- Add the equivalent CLI `--delete-source` option and relative output-directory
  handling.
- Translate the complete workflow into Czech, German, French and Russian.

## Verification

The GUI, CLI, updater and integration projects were built with Qt 6.10.1,
MSVC x64 and Open CASCADE 8.0.0. Five focused tests passed with real
Ghostscript, covering replacement, failure preservation, relative output,
conditional source deletion and destination collisions. The dedicated GUI
workflow check and all four translation catalogs also passed.

This release targets Windows x64 and includes matching source code and signed
updater metadata. Linux clients continue to use the latest release containing a
verified Debian runtime.
