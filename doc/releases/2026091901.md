# ZIMA-CAD-Parts 2026091901

## Startup and navigation

- Open the main window directly. Remove the splash screen, its image and its
  General settings section; obsolete preferences are cleared on the next save.
- Place Settings at the far right of the top toolbar, after the command-panel
  button.

## File tools

- Show PTC Cleaner, ZIMA-CAD Cleaner and PostScript-to-PDF candidates in one
  checkbox list without column headings. Successful items disappear as each
  operation completes; unchecked and unsuccessful items remain.
- Report failures below the list and in file tooltips. Full reasons and results
  remain available in CLI JSON.
- Limit the ordinary PDF window to its source directory and remove its recursion
  checkbox. Explicit CLI and captured AI recursive requests remain supported.
- Check **Delete PS source files after creating PDF** by default in the GUI.
  Uncheck it to retain sources. Deletion occurs only after a successful PDF save
  and respects the source directory's lock; changed source files are preserved.
  This source deletion is permanent. CLI deletion still requires `--delete-source`.
- Add **Clean ZIMA-CAD files** to the directory context menu and `zima-clean` to
  the CLI, command panel and AI preview/approval flow. Every numbered archive of
  `.prtz`, `.asmz`, `.drwz`, `.frmz` and `.tblz` is a candidate, including the
  highest number and archives with no current document. Unnumbered documents and
  unrelated file types remain untouched.
- Both Cleaners use the system trash and respect local directory locks. System
  directories and links are excluded. Files are revalidated before removal.
- Update Czech, German, French and Russian UI translations and English guides.

## Verification and distribution

The local Windows build passed a clean Qt 6.10.1/MSVC x64/OCCT 8.0.0 build,
56 integration checks, 14 tool CLI tests, four read-only CLI tests and all four
translation catalogs (562 messages each). Czech tool dialogs were rendered and
inspected. See [verification](../verification.md) for exact scope and limitations.

The Windows x64 ZIP uses the shared `ZIMA-CAD-Parts/` layout with root launchers,
the versioned Windows runtime, matching committed sources and license notices.
Publication requires a clean tagged build, packaged-runtime tests, signed
updater metadata and complete archive/source checksum validation. Extract it
and run `ZIMA-CAD-Parts/ZIMA-CAD-Parts.exe`.

This release includes Windows only. Linux clients continue using the latest
release that contains their verified Debian runtime. Adding a Linux build after
publication requires a new release number; published assets are immutable.
