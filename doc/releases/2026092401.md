# ZIMA-CAD-Parts 2026092401

Interaction colours now match ZIMA-CAD: confirmed selection and active tabs or
commands are azure (`#00D1FF`); pointer hover is green (`#4DD811`). Highlighted
text is black. Selected tree rows remain azure under the pointer; active buttons
and tabs temporarily turn green. Menus and generated directory tiles use the
same hover colour. Selection, editing and file operations are unchanged.

Trees retain platform rendering, branch markers, indentation and fonts. The
navigation panel inherits the desktop palette instead of forcing dark colours,
Arial and custom scrollbars. The datasource retains its 32-pixel icons through
the ordinary Qt API. See [interaction colours](../interaction-colours.md).

The libqdxf update only removes the executable flag from its Visual Studio
project file; no library source or DXF behavior changes. Untracked Pro/E files
and other local working files are not part of this release.

The full local GUI/CLI/updater build and all 60 integration checks passed.
Coverage includes native tree metrics, exact hover/selection fills, inactive
selection, real pointer enter/leave, selection preservation, translations and
existing datasource/file workflows. All four translation catalogs passed
validation; the change introduces no UI strings. Windows native rendering was
also checked visually. Native Linux desktop rendering still requires validation
on the Linux host; this release contains Windows only.

Signed portable acceptance and publication are recorded after package checks.
