## Scope

and synthetic web/CAD fixtures. Browser/credential/CAD acceptance uses a harness
with matching application objects and packaged dependencies; the shipped GUI
also received its own startup probe. This is not a separate clean-VM or exhaustive
supplier-account/download audit. Headless integration tests use software GPU
rendering; normal native application rendering remains enabled.

This is the independently named ZIMA-Parts product. Existing ZIMA-CAD-Parts data
and published archives are preserved; automatic migration from that former
product is not provided. There was no previous public Linux build under this
standalone identity, so live installation/rollback from a preceding official
standalone Linux release is not claimed; eighteen isolated updater tests cover
those operations. ZIMA-CAD is unchanged by this release.
