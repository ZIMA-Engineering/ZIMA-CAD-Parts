# ZIMA-Parts 2026093001 — Debian 13 Linux

This Linux release builds the current standalone ZIMA-Parts product, including
native folder/file icons and the light/dark application-icon and directory-logo
contrast improvements previously verified on Windows. It includes the GUI, CLI,
updater, native dependencies and matching committed sources.

No application behavior or user-visible strings change for this platform release;
the build identity is updated. Localization will be validated before publication.
Debian supplies libc and graphics drivers. Ghostscript remains a required system
package for PS2PDF. Existing ZIMA-CAD-Parts installations retain their historical
identity; this is the independently named ZIMA-Parts product.
