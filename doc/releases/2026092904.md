# ZIMA-Parts 2026092904

Directory Tree entries without a custom datasource logo now use the native
platform folder icon. File icons in the Parts tab also come from the platform,
including its registered file associations and fallback for unknown types.
Numbered archive files follow their actual filename. File detection, archive
filtering, thumbnails, metadata and command icons retain their existing behavior.

Both providers use Qt's native QFileIconProvider on Windows and Linux. Linux
appearance follows the desktop theme/platform integration available to Qt;
Windows validation does not establish native Linux desktop acceptance.

No user-visible strings changed. Translation catalogs are reviewed and validated
with this change. Application action icons remain black and azure; custom
supplier/datasource logos keep precedence over the system folder icon.

Windows release validation and publication are pending.
